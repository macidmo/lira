# Telegram Currency Bot 💱

بوت تيليجرام احترافي يعرض أسعار صرف **الدولار الأمريكي**، **اليورو**، و**الليرة السورية**
مقابل **الليرة التركية**، وينشر تحديثًا تلقائيًا داخل قناة تيليجرام **كل ساعة تمامًا**.

مبني بالكامل بلغة Python باستخدام **aiogram 3.x** بشكل Async، ويعتمد حصريًا على
[ExchangeRate-API](https://www.exchangerate-api.com/) كمصدر للبيانات.

## 1️⃣ إنشاء بوت من BotFather

1. افتح تيليجرام وابحث عن [@BotFather](https://t.me/BotFather).
2. أرسل الأمر `/newbot` واتبع التعليمات (اسم البوت، ثم username ينتهي بـ `bot`).
3. سيعطيك BotFather **التوكن (Token)** الخاص بالبوت، احتفظ به — سنحتاجه في الخطوة التالية.

---

## 2️⃣ الحصول على API Key من ExchangeRate-API

1. أنشئ حسابًا مجانيًا على [exchangerate-api.com](https://www.exchangerate-api.com/).
2. من لوحة التحكم (Dashboard) انسخ الـ **API Key** الخاص بك.

---

## 3️⃣ الحصول على CHANNEL_ID الخاص بالقناة

1. أنشئ قناة تيليجرام (أو استخدم قناة موجودة).
2. أضف البوت الذي أنشأته إلى القناة **كمشرف (Admin)** مع صلاحية **نشر الرسائل**.
3. لمعرفة معرّف القناة (Channel ID):
   - إذا كانت القناة عامة (Public)، يمكنك استخدام معرّف المستخدم مباشرة، مثل:
     `CHANNEL_ID=@my_channel_username`
   - إذا كانت القناة خاصة (Private)، أرسل أي رسالة داخل القناة ثم حوّلها (Forward)
     إلى بوت مثل [@userinfobot](https://t.me/userinfobot) أو [@JsonDumpBot](https://t.me/JsonDumpBot)
     لمعرفة الـ ID، وسيكون بالشكل: `-100XXXXXXXXXX`

---

## 4️⃣ إعداد ملف `.env`

انسخ ملف `.env.example` وأعد تسميته إلى `.env`:

```bash
cp .env.example .env
```

ثم افتح الملف وضع القيم الخاصة بك:

```env
BOT_TOKEN=هنا_توكن_البوت_من_BotFather
API_KEY=هنا_مفتاح_ExchangeRate-API
CHANNEL_ID=هنا_معرف_القناة
HASFIYAT_API_KEY=هنا_مفتاح_Hasfiyat_API
```

اختياريًا يمكنك تغيير مصدر الذهب أو الرمز (الافتراضي `harem` و`GRAM ALTIN`):

```env
GOLD_SOURCE=harem
GOLD_SYMBOL=GRAM ALTIN
```

> ⚠️ لا تشارك ملف `.env` مع أي أحد، ولا ترفعه إلى GitHub.

## 6️⃣ تشغيل المشروع

```bash
python bot.py
```

عند التشغيل الناجح ستظهر رسالة مشابهة لـ:

```
✅ تم تشغيل البوت بنجاح.
```

سيبدأ البوت فورًا بالرد على الأوامر، وسيقوم تلقائيًا بنشر تحديث الأسعار
داخل القناة عند بداية كل ساعة (مثلاً: 10:00، 11:00، 12:00...).

---

## 7️⃣ إضافة البوت للقناة وإعطاؤه صلاحية النشر

1. افتح إعدادات القناة في تيليجرام.
2. اختر **Administrators** → **Add Admin**.
3. ابحث عن البوت الخاص بك وأضفه.
4. فعّل صلاحية **Post Messages** (نشر الرسائل) على الأقل.
5. احفظ التغييرات.

بدون هذه الصلاحية لن يستطيع البوت نشر تحديثات الأسعار داخل القناة.

## 🖥️ طريقة الاستخدام

- أرسل `/start` للبوت للحصول على القائمة الرئيسية.
- اضغط على أي زر (💵 الدولار / 💶 اليورو / 🇸🇾 الليرة السورية / 💱 جميع الأسعار)
  لعرض السعر الحالي مباشرة.
- سينشر البوت تلقائيًا رسالة جديدة بجميع الأسعار داخل القناة كل ساعة تمامًا،
  حتى لو لم يتغير السعر عن التحديث السابق.

## 🥇 الذهب

- المصدر: [Hasfiyat API](https://altinapi.hasfiyat.com/docs)، ويعطي سعر عيار 24 فقط.
- عيار 21 يُحسب رياضيًا: `سعر 21 = سعر 24 × 21 ÷ 24` (أي × 0.875)، للبيع والشراء معًا.
- السعر المعروض هو سعر الذهب الخام فقط، بدون مصنعية.
- يوجد كاش 60 ثانية لتقليل استهلاك حصة الـ API.
- لو فشل جلب الذهب، تُنشر العملات كالمعتاد بدونه.

## 🛠️ معالجة الأخطاء

- إذا فشل الاتصال بـ ExchangeRate-API (مثلاً بسبب مشكلة شبكة أو تجاوز حد الطلبات)،
  فإن البوت **لا يتوقف عن العمل**، بل يسجل الخطأ في ملف `logs/bot.log`
  ويحاول تلقائيًا مجددًا عند موعد التحديث القادم.
